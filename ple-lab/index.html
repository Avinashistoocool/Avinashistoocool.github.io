01 / THE MECHANISMMODEL / OFFLOAD / INSPECTION

THE DESIGN QUESTION

Large table.
Small transfer.

A normal embedding gives a token one vector. Here a token has six separately indexed, jointly trained 64-dimensional slices—one for each transformer block. The token IDs of a forward pass are known before that pass runs, so their rows can be fetched from CPU RAM or a memory-mapped file instead of keeping the entire table in GPU memory.

For ple-small, one fp16 row is 768 bytes; the whole fp16 table is 38.6 MB. Offloading is a memory strategy, not free acceleration: the latency measurements below show the cost.

Removing only layer 0’s token input raises validation loss by +0.090 nats per prediction.

At each block, its token slice is combined with a projected initial-embedding context vector before the gated projection adds to the residual stream. The context term remains active in each single-layer ablation. Layers can compensate: their individual losses do not add up to the all-layer ablation. Model contract ↗ · Ablation definition ↗
